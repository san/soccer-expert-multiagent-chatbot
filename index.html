⚽Soccer Expert Multi-Agent Chatbot

Intelligent AI-Powered Soccer Knowledge System

Powered by: Google ADK • Gemini 2.5 Flash • FAISS RAG • Tavily Web Search

A production-ready multi-agent conversational AI system that routes queries to specialized agents for expert soccer knowledge with real-time information retrieval.

Problem & Solution

The Challenge

  • Soccer questions vary widely in scope
  • Need for both historical data and real-time info
  • Complex routing between knowledge types
  • Maintaining context across conversations

Our Solution

  • Multi-agent architecture with intelligent routing
  • Adaptive data source selection
  • RAG for verified historical knowledge
  • Web search for real-time information

System Architecture

User Query

Frontend sends to FastAPI Backend
Orchestrator analyzes query intent

Intelligent Routing:

General Soccer → Soccer Expert Agent (RAG Only)
2026 World Cup → World Cup Analyst (Web Search Only)
Past World Cups → World Cup Analyst (RAG First, Web Search if Needed)

Core Features

🧠 Intelligent Agents

Soccer Expert & World Cup Analyst with specialized knowledge

📚 RAG System

FAISS indexing for semantic search over verified knowledge base

🌐 Web Search

💬 Conversation Memory

Real-World Use Cases

📖 General Soccer Questions "Explain the offside rule" → Soccer Expert (RAG) → Verified knowledge from Laws of the Game
📊 Historical World Cup Data "Who was top scorer in 2018?" → World Cup Analyst (RAG) → Tournament records with optional web verification
🔮 Future Tournament Info "Qualification rules for 2026?" → World Cup Analyst (Web Search) → Real-time tournament information
💬 Multi-Turn Conversations Maintains context across messages → Session memory → Coherent dialogue
